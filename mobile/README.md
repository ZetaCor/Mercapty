# Mercapty · app para iPhone y Android

App de Expo (React Native, SDK 57) que usa la API de la web. Qué hace, cómo probarla en el celular y cómo
publicarla: [README principal](../README.md#app-para-iphone-y-android-mobile).

```bash
npm install
npx expo start     # escanea el QR con Expo Go
npx tsc --noEmit   # revisa los tipos
```
